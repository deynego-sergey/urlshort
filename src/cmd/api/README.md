### Сводная таблица API-методов (Actions)

| Тип доступа | Action | Описание | Входной Payload | Тип ответа |
| :--- | :--- | :--- | :--- | :--- |
| Публичный | auth:register | Регистрация нового аккаунта (статус pending) | `{"username": "...", "password": "..."}` | `{"message": "..."}` |
| Публичный | auth:confirm | Подтверждение регистрации по токену | `{"token": "..."}` | `{"message": "..."}` |
| Публичный | auth:login | Аутентификация (выдача JWT + HTTP-Only Cookie) | `{"username": "...", "password": "..."}` | `{"access_token": "..."}` |
| Публичный | auth:refresh | Ротация сессии через HTTP-Only Cookie | *Отсутствует* | `{"access_token": "..."}` |
| Публичный | auth:request_reset | Запрос токена для восстановления пароля | `{"username": "..."}` | `{"message": "..."}` |
| Публичный | auth:reset_password | Сброс пароля при наличии валидного токена | `{"token": "...", "new_password": "..."}` | `{"message": "..."}` |
| Защищенный | link:create_batch | Массовое или одиночное создание ссылок | `[{"original_url": "..."}]` | `{"links": [...]}` |
| Защищенный | link:list | Получение списка ссылок с фильтрацией и поиском | `{"search": "...", "is_deleted": false}` | `{"links": [...]}` |
| Защищенный | link:update_batch | Резерв: Массовое обновление оригинальных URL | `{"ids": [...], "new_url": "..."}` | В реализации |
| Защищенный | link:delete_batch | Резерв: Массовое мягкое удаление ссылок | `{"ids": [...]}` | В реализации |
| Защищенный | analytics:summary | Резерв: Общая сводная статистика по кликам | В реализации | В реализации |
| Защищенный | analytics:link_details | Резерв: Детальная аналитика по ссылке | В реализации | В реализации |
| Защищенный | analytics:top_links | Резерв: Список самых популярных ссылок | В реализации | В реализации |
